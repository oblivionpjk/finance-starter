# REITs 行情分析与横向对标系统 · 设计方案

> **文档状态**：v1.1 · 2026-11-20 · **方案已完成实现**（P0–P3 + 独立页面 + PDF/PNG 下载 + 扩展机制）
> **适用工程**：`finance-starter`（现有 A 股财务分析系统）
> **一句话定位**：另开一个页面，上传 WIND 导出的 REITs 行情 Excel，系统自动解析、计算、生成**数据分析报告（PDF）+ 图片（PNG）**，并输出**华安百联 REIT 与其他 REITs 的横向对标**。
> **与前案关系**：取代已删除的「消费 REITs 月报资料收集方案（v0.3）」。前案是"从多个免费源采集拼数据"，本案收敛为"从用户提供的 WIND Excel 出发做分析"，数据链路大幅简化。

---

## 0. 本方案最重要的一句话

**这一份 WIND Excel 只有「日频行情」（收盘价 + 成交金额），没有出租率、营收、分派率、估值等任何基本面数据。** 因此它能完整支撑的是**二级市场表现维度**的横向对标（走势、涨跌幅、波动、回撤、流动性、成交额），而 PDF 第三部分的**基本面对标（3.6.4 分派率 / 3.6.5 财务 / 3.6.6 运营 / 3.6.7 评估）无法由它单独产出**。方案据此分两层：本期做「行情版」，基本面版列为可选扩展（第 11 节）。

如果把"复现 PDF 第三部分全部图表"当作验收目标，本项目会名不副实——这是必须先对齐的边界。

### 1.4 数据准确性核对（重要发现，写入硬约束）

实测发现 **PDF 报告正文的若干数值与 WIND 原始 Excel 不一致**：

| 项 | PDF 报告值 | WIND Excel 原值（2026-11-16） | 核验 |
|---|---|---|---|
| 华安百联收盘价 | 2.33 元 | **2.541 元** | 全样本最低 2.383，2.33 从未出现 |
| 华夏华润收盘价 | 4.00 元 | **9.906 元** | 华润全样本 8.603~11.104，4.00 不存在 |
| 华安百联年初至今跌幅 | -19.25% | 用 2.541 反算 = **-19.26%** ✅ | 用报告的 2.33 反算 = -25.96% ❌ |

结论：报告自身跌幅数据反证了 11-16 收盘价应为 2.541，报告正文的"2.33/4.00"疑为**口径混淆（如用了基金净值 NAV）或错填**。系统必须遵守：**所有数值一律从 WIND 原始行情重算，绝不照抄报告正文结论**；如需与报告对照，单列"差异说明"，标注疑似原因，不擅自替报告圆场。

## 2. 能力边界与本期范围

### 2.1 本期（行情版）做得到

- 解析 12 个 sheet → 标准化日频行情库；
- 华安百联 vs 其余 11 只的**二级市场横向对标**：归一化走势、区间/年初至今/上市至今涨跌幅、年化波动率、最大回撤、日均成交额、成交额活跃度、两两相关性；
- 生成 PDF 数据分析报告 + 一组 PNG 图片；
- 数据质量报告（口径、缺失、异常值、样本区间）。

### 2.2 本期做不到（明确告知，不伪造）

- 总市值、分派率、营收/EBITDA/可供分配金额、出租率/收缴率/租金、资产评估值——**因 Excel 无此数据，一律留空并标注"待补，需另据基金季报/评估报告"**，不估算、不编造；
- 大盘指数对比曲线——Excel 无指数序列，本期仅做"百联 vs 同业"，指数对比列为可选扩展。

### 2.3 范围守则

- 不做投资建议、买卖判断、目标价、行业分位倍数；
- 不接语言模型，报告叙述为**确定性模板**；
- 报告主格式 **PDF**，图片 **PNG**；不产 PPT。

## 3. 解析层设计（WIND Excel → 标准数据模型）

### 3.1 解析流水线

```
WIND .xls
  → 格式探测（真 xls / xlsx / 伪装 csv）
  → 逐 sheet 遍历（每个 sheet = 一只 REIT）
      → 识别标的：sheet 名 + 表头 `简称['代码]` 正则提取 6 位代码
      → 补市场：508/5080→SH，180/181→SZ
      → 表头规范化：列名无"收盘价"字样 → 按配置标注为"未复权收盘价(元)"
      → 逐行读取：Excel 日期序列号 → YYYY-MM-DD；价格/成交额转 float
      → 剔除尾部：空行 + "数据来源：Wind" 注释行
      → 质量校验：日期单调、价格>0、无重复交易日
  → 汇总为统一长表 daily_quote(date, code, name, market, close, amount_million)
  → 输出解析报告：12 只 / 各区间 / 起止日 / 异常行 / 口径提示
```

### 3.2 关键解析规则（写死为确定性规则，不用运行时推断）

1. **代码提取**：表头 `<简称>['<6位代码>]` 用正则 `\['(\d{6})` 提取；提取失败则报 `CODE_EXTRACT_FAILED`，不猜。
2. **价格字段语义**：系统固定标注"未复权收盘价（元）"，不作可配置项、不逐次人工确认。口径来源（WIND 日行情导出模板，价格列表头无口径字样）与反算交叉验证依据写入报告第 1 节、质量 JSON 与图表脚注；WIND 换模板或换数据源时由新解析器在注册时声明口径。
3. **成交额单位**：表头已含"百万元"，直接采用，不做换算。
4. **异常值**：上市首日成交额显著放大（实测华夏凯德 429、唯品会 401 百万）→ 默认保留但打 `listing_day` 标记，流动性均值统计可选剔除。
5. **样本不齐**：各标的起点不同，统一构造两层时间轴——**全样本轴**（保留 NaN，用于各自上市至今）与**公共窗口轴**（12 只齐全，用于公平横向对比，默认 2025-10-31 起）。

### 3.3 标准数据模型（领域层）

```python
ReitQuote(date, code, name, market, close, amount_million, is_listing_day)
ReitMeta(code, name, market, listing_date, price_field="unadjusted_close", price_unit="CNY")
AnalysisTask(period, source_file, parsed_at, price_basis, quotes[], quality_report)
```
与 A 股系统一致，采用 dataclass + JSON 原子落盘，**本模块独立目录，不改 A 股任何代码**。

## 4. 指标体系与口径

### 4.1 单标的基础指标（可算，纯函数）

| 指标 | 口径 | 备注 |
|---|---|---|
| 期末收盘价 | 时点 = 2026-11-16（数据最新日，单一 `snapshot_date`） | 全报告锁定同一时点 |
| 区间涨跌幅 | 期末价 / 期初价 − 1；期初按"年初首个交易日"或"上市首日" | 与报告 -19.25% 对齐需用年末最后交易日基准，见 4.3 |
| 年化波动率 | 日收益率标准差 × √252 | 公共窗口内计算 |
| 最大回撤 | 区间内 (峰值→谷底) 最大跌幅 | 归一化曲线上标注 |
| 日均成交额 | 成交额均值（百万元），可剔除上市首日 | 流动性维度 |
| 累计收益曲线 | 基期归一化 = 100 | 用于走势对比 |

### 4.2 横向对标指标（华安百联 vs 同业）

1. **归一化走势图**：12 只公共窗口累计收益曲线，华安百联加粗高亮；
2. **涨跌幅对比**：年初至今 + 上市至今两张横向条形图，华安百联标色；
3. **风险收益散点**：年化波动率 × 区间收益，标注百联位置；
4. **回撤对比**：各标的最大回撤横向对比；
5. **流动性对比**：日均成交额横向条形；
6. **相关性热力图**：12×12 日收益相关性矩阵，百联一行高亮。

每张图附：数据来源 `WIND：<文件名>`、数据时点、口径脚注、样本区间。

### 4.3 与 PDF 数值对齐的处理原则

- 年初至今跌幅：提供两种基准口径（首个交易日 / 上年最后交易日），**默认用能复现报告 -19.25% 的口径**（实测为 2025-12-31 基准），并在脚注写明；
- 报告正文与 Excel 冲突处（2.33/4.00）：报告章节单列"与集团报告数值差异说明"，给出重算值 + 疑似原因（NAV 口径？错填？），**不修改也不背书原报告**。

## 6. 系统架构与模块划分

延续 A 股系统分层惯例，**新增独立模块 `app/reits_analysis/`，与主链路并列、互不改动**：

```
app/reits_analysis/
  config.py        # 时点、字段口径、路径、阈值等配置
  parser.py        # WIND Excel → 长表（E）
  model.py         # ReitQuote/ReitMeta/AnalysisTask + 口径纯函数
  quality.py       # 解析质量报告与异常检测
  metrics.py       # 单标的 + 横向对标指标（纯函数）
  report.py        # PDF 报告（复用 reporting/pdf.py 的渲染能力）
  charts.py        # 8 张 PNG（复用 rendering/charts.py 中文字体）
  service.py       # 门面：upload→parse→analyze→generate
app/api/reits_analysis.py   # 独立 APIRouter：/api/v1/reits/*
web/reits.*                  # 独立页面（html/js/css）
```

**复用现有**：FastAPI 服务骨架与 `/static` 挂载、`app/errors.py` 错误码、中文字体配置、PDF 渲染、会话/临时目录隔离机制。
**不改动**：A 股 `app/domain`、`app/engine`、`app/api/server.py` 除挂载新路由外的任何逻辑、`web/index.html` 除一个导航链接外的任何内容。

## 9. 数据留存与安全

- 遵循项目既定约束：**上传文件与产物仅当前会话留存**（临时目录 + TTL + 页面关闭销毁），不写数据库、不长期入库；
- 上传后缀校验（xls/xlsx），路径隔离，产物下载做路径穿越防护；
- 解析失败/格式异常 → 明确错误码，不生成半成品报告。

> 说明：本数据是公开市场行情，比内部三大报表敏感度低；但为保持约束一致，默认仍按会话留存。若后续需要按月归档做环比，可在第 11 节扩展时单独申请放宽，本案默认不留。

## 10. 校验与口径红线

1. **数值可回溯**：报告/图中每个数能定位到 `code + date + 字段`；数字一致性校验（报告内带小数数值须全部登记），出现未登记数字即中止交付。
2. **单一时点**：所有期末价/涨跌幅锁定同一 `snapshot_date`（数据最新日 2026-11-16 或用户指定）。
3. **不照抄、不编造**：报告正文冲突数值以 Excel 重算为准；缺失的基本面字段写"待补"，不插值、不补零。
4. **样本公平**：横向对比默认用公共窗口；用全样本时标注各标的长度差异。
5. **上市首日标记**：成交额均值可剔除首日，默认保留并标注。
6. **口径固定标注**：默认按未复权收盘价处理，写明来源（WIND 日行情模板）与反算交叉验证依据；不设"待核/定稿"两态，换模板由新解析器声明口径。

## 14. 风险

1. **范围期待落差**（最大）：用户可能以为一份 Excel 能复现 PDF 全部对标——需在页面首屏与报告第 6 节持续明示缺口，避免交付被判"缺失功能"。
2. **报告数值错误背书风险**：PDF 的 2.33/4.00 与原始数据冲突，必须显式标注差异，不替其圆场，也不据此改我们的重算值。
3. **价格口径未确认**：是否复权直接影响收益率，未确认前报告标"待核"。
4. **样本不齐**：新上市标的起点晚，公平对比必须用公共窗口，否则百联"上市至今"与其他标的不在同一时间尺度。
5. **xls 兼容性**：老式 `.xls` 需适配读取库；伪装格式需探测拒绝。

## 15. 实现状态（v1.1 · 2026-11-20）

第 12 节的 P0–P3 已全部落地，另按用户新增要求补齐四项能力：

1. **PDF 与 PNG 支持下载**：`GET /api/v1/reits/artifacts/{key}?session_id=...` 以 `Content-Disposition: attachment` 返回；页面提供「下载 PDF 报告」「下载解析与质量 JSON」按钮，每张 PNG 右上角有下载图标。产物只认会话内登记的文件名，杜绝路径穿越。
2. **只实现本份 Excel 可得到的数据分析，但支持扩展**：本期仅注册 `quote` 维度；`distribution / financial / operation / valuation / index` 在 `DIMENSIONS` 中已声明为未实现，报告首屏与第 6 节统一标注「待补」。后续上传其他 Excel 走同一上传接口按维度累积；未识别为专用维度的文件作为 `attachments` 附加数据集保留，PDF 第 7 节输出工作表结构与行数概览（不推断其数值），页面同步提示。新增专项内容只需 `parser.register_parser`，按需再注册 `metrics.register_provider` / `report.register_section` / `charts.register_charts`，服务层、API、页面不改。
3. **基准标的全局生效**：页面选择基准后，指标、报告第 3/4 章、PDF 元数据与页脚、8 张图的标题/图例/脚注/高亮、PDF 文件名全部跟随；结果区已生成时切换基准会自动重算刷新，产物 URL 带版本号防止浏览器缓存旧图。上传的工作簿不含当前基准时自动切换到首只标的。第 5 节「与集团报告数值差异说明」是固定对照项，明确标注与当前基准无关。
4. **价格口径改为固定标注**：核查发现原「价格字段口径确认」不参与任何数值计算，只切换文字标签与「待核/定稿」提示，且这份 WIND 模板的口径已由收盘价反算集团报告跌幅交叉验证。据此删除该确认步骤与 `confirm-field` 端点、页面确认面板及两态标记；口径统一由 `PRICE_BASIS` 固定标注（标签、来源、依据、扩展规则），写进报告第 1 节、质量 JSON 与图表脚注。将来 WIND 换模板或换数据源，由新解析器注册时声明口径，不恢复人工点选。
